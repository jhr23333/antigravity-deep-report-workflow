## 一、国金原生 Word 样式映射表

基于对 `国金证券_公司深度研究模板.docx` 及《屹唐股份》《北方华创》等样本报告的 XML 逆向解析，脚本严格调用以下原生 `style_id`：

| Markdown 语法 / 逻辑元素 | 国金 Word 原生 `style_id` | 排版与质控规则（实测对齐官方模板与《天通股份》《北方华创》） |
|---|---|---|
| 首页报告主标题 | 无样式（显式 XML） | **`思源黑体 CN Heavy`、18pt、加粗、深蓝 `#004A70`**；≤ 20 字（含标点） |
| 首页摘要小标题（投资逻辑等） | `SummaryTitle` | **`思源黑体 CN Regular`、12pt（小四）、加粗、深蓝 `#004A70`**（严禁改用 `SummarySubTitle`） |
| 首页摘要正文 | `SummaryContentNoFirLinIndent` | **楷体、五号（10.5pt）、黑字、原生无首行缩进**；投资逻辑须融入最新核心行业数据 |
| 目录后 / 附录前换页 | `<w:br w:type="page"/>` | **双硬换页符**：图表目录结束后必须换页起第一章；第五章风险提示结束后必须换页起“附录：三张报表预测摘要” |
| `# 一、一级标题` | `ContentFirTitle` | `思源黑体 CN Regular` 12pt 加粗深蓝 `#004A70`，左缩进 `2552 dxa`；≤ 20 字；不另起页、不空行 |
| `## 1.1 二级标题` | `ContentSecTitle` | 楷体加粗，左缩进 `2552 dxa`；≤ 26 字；不空行 |
| 普通正文段落 | `ContentContentNoFirLinIndent` | 楷体/黑色，左缩进 `2552 dxa`；禁止斜体、下划线、标红；段间不空行；除标题外每页最多 1 处加粗且 ≤ 2 行 |
| 图表标题（**模板自动编号，不手动加前缀**） | `ContentGraphTitle` / `ContentGraphTitleSuo` | **严格保留模板原生样式：楷体、五号（10.5pt）、加粗、斜体、黑字**（严禁手动设 `bold=False` 覆盖）；下带国金深蓝横线 |
| 图表来源标注 | `ContentResource` / `ContentResourceSuo` | 楷体 7.5pt；格式统一为 `来源：<具体公开机构/公告>、国金证券研究所`（**严禁写“公开行业资料/产业链公开拆解”**） |
| 单图宽度（默认 `OneFullText`） | 容器表 `8192 dxa` + `tblInd=2551` | **常规单图默认与正文左侧对齐（保留国金左侧留白栏）**；仅超宽时间轴/股权架构/客户矩阵加 `width: full` 走 `OneFullPage`（`10743 dxa`） |
| 双图并排（`TwoHalfPage`） | 容器表 `5244 / 255 / 5244 dxa` | 左右两图各自独立带国金深蓝上下横线 |
| 数据表格 | `GJ_Styles_Table_DefalutStyle` | **统一楷体、9pt（比正文小一号）、全部单元格水平与垂直居中（含首列）**；国金深蓝表头、浅灰隔行；常规表默认 `OneFullText` 缩进宽，5 列以上宽表可设 `width: full` |

## 三、`report_meta.json` 封面元数据格式

用于填充模板首页左侧（报告标题、投资逻辑、盈利预测、估值与评级、风险提示），同时**严格保护**首页右侧主要财务指标表及文末附录三张报表摘要不被破坏：

```json
{
  "company_name": "示例科技",
  "stock_code": "688000.SH",
  "report_title": "卡位先进制程核心设备，国产替代加速兑现",
  "rating": "买入",
  "rating_type": "首次覆盖",
  "target_price": "85.00元",
  "report_date": "2026年11月23日",
  "summary_sections": [
    {
      "heading": "投资逻辑",
      "paragraphs": [
        "核心逻辑第一段（控制在首页篇幅内）...",
        "核心逻辑第二段..."
      ]
    },
    {
      "heading": "盈利预测、估值和评级",
      "paragraphs": [
        "预计公司2026-2028年营业收入分别为XX/XX/XX亿元，归母净利润分别为XX/XX/XX亿元，对应PE分别为XX/XX/XX倍。参考可比上市公司估值水平，给予公司2027年XX倍PE，对应目标价85.00元，首次覆盖给予“买入”评级。（注：严禁在首页摘要中列出未覆盖可比公司名称）"
      ]
    },
    {
      "heading": "风险提示",
      "paragraphs": [
        "下游晶圆厂资本开支不及预期；新产品客户端验证进度不及预期；股东解禁及减持风险（若近3月/后6月存在解禁须写明）。"
      ]
    }
  ]
}
```

## 四、模板锚点保护与质控自动检查

`render_docx.py` 运行时会自动执行以下保护与校验：
1. **标题长度红线校验**：若 `report_title` 超过 20 字（含标点），脚本输出 `🔴 质控警告`。
2. **极端词与禁用格式扫描**：扫描全文是否包含质控禁止的极端词或 `*斜体*` / `<u>下划线</u>`。
3. **锚点精准替换**：只替换模板中 `[11]~[13]` 的正文占位段落，完整保留 `[05]` 首页右栏股票信息/财务表、`[08]` 自动目录域、`[14]` 附录三张报表预测摘要及 `[16]~[26]` 评级说明与特别声明。
4. **打开后唯一手动步骤**：在 Word 中打开生成的 `<公司名>_深度报告.docx`，按 `Ctrl+A` → `F9` 更新目录页码，再使用国金 Word 插件导入首页财务摘要表与文末三张报表即可提交风控。
