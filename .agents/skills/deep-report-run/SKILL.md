# 国金电子深度报告端到端总控工作流

本 Skill 串联公司深度研究报告从立项到发版的全流程。所有正文文风、模板参数、合规黑名单均以 `D:\深度报告\脚本与规范\` 为**唯一真源**，不在本文件重复抄录。

## 目录与单一真源

- 完整 SOP 与 `00–09` 文件夹说明：`D:\深度报告\脚本与规范\workflow_sop.md`
- 文风与质控 12 条红线：`D:\深度报告\脚本与规范\style_guide.md`
- 模板与图表配色：`D:\深度报告\脚本与规范\report_template_spec.md`、`chart_theme.json`
- 工作底稿六道门禁：`D:\深度报告\脚本与规范\workpaper_spec.md`
- 关联子 Skill（可按阶段单独调用）：
  - `deep-report-review`：Step 3.5 独立联网红队审稿与终稿签认（首选 Opus 5.5，支持 Sonnet/Gemini/ChatGPT）
  - `deep-report-charts`：Step 5A 制图、三端有序对账与 Word 渲染验收
  - `deep-report-workpaper`：Step 5B 自动整句红框截图与合规工作底稿 Excel 打包

## 端到端 6 步执行流程（与 `workflow_sop.md` 严格对齐）

### Step 1：立项建目录与按需取数
1. 在 `D:\深度报告\{公司名}\` 下建立标准子目录：`00_原始资料\pdfs\`、`00_原始资料\内部参考_禁入底稿\`、`04_分节草稿\`、`07_图表\`、`08_底稿证据\`。
2. **基础财务/行情优先走 iFinD，但必须与近 90 天全部临时公告交叉核对**：
   - 常规财务/行情优先走 iFinD（`~/.ifind/ifind_helper.py` 或 iFinD MCP，底稿享免截图豁免）；
   - **近 90 天全量公告无过滤扫描（防漏重大催化）**：立项时必须拉取公司最近 90 天**全部**交易所临时公告标题清单（禁止只按“合同/定增”关键词过滤），避免遗漏近期《生产经营情况公告》、自建基地开工、筹划 H 股/再融资、回购等关键进展；
   - **股本与实控人持股以最新发行/权益变动公告 PDF 为唯一真源**（不轻信 iFinD 衍生汇总字段）；三季报/季报须同步核查**交易性金融资产**（广义现金）、**所得税费用/少数股东损益**，以及反推**最新单季毛利率与单季经营现金流**。
3. **按需后台自动抓取 2–3 份核心公开 PDF**（最新一期季报/半年报/年报、招股书、最新定增/聆讯稿或近 90 天重大经营公告），用于：① 提取非标准附注明细（在建工程、交易性金融资产、分基地产能、在研项目、前五大客户）；② 生成工作底稿整句/整行红框原件截图。
4. 运行财报分节精确提取脚本（必抽核心科目缺失时非零退出，禁止跳过）：
   ```powershell
   D:\anaconda3\python.exe D:\深度报告\脚本与规范\pull_company_data.py `
     --name {公司名} --code {股票代码} `
     --pdf D:\深度报告\{公司名}\00_原始资料\pdfs\{最新财报}.pdf `
     --out D:\深度报告\{公司名}\00_原始资料\01_最新财报全科目快照.md
   ```
5. 产出共享锚点 `01_全篇主线卡与禁重分工表.md`、`02_统一术语与数字口径表.md`，并调 `zsxq-topic` 摸底知识星球观点落盘至 `内部参考_禁入底稿\`（严禁入正文/底稿）。

### Step 2：段落级论点大纲（必须停下来等研究员确认）
- 读取 `workflow_sop.md` 与 `style_guide.md`，边搜边产出 **`03_段落级大纲.md`** 与 **`00_原始资料\02_行业公开数据包.md`**（章节数量按公司业务结构灵活设定，每个二级节不少于 3–4 段，标题均为论点句）；
- **两阶段强制联网检索 + 一手 URL 落盘**：
  1. **一阶段宽搜定框架 → 二阶段单点深搜核验**：严禁用一条大杂烩宽搜摘要撑起整章数据；对大纲中每一个核心行业数字、技术协议/物理规格（如基板尺寸、接口速率）及海外竞品最新财报，必须单独起窄关键词 query 核验一手原文，并对每个核心行业机构数据加当前月份/近两月词补搜一次（防引用过时旧预测）；
  2. **真实文章页 URL / 官方 IR PDF 强制落盘**：必须在 `02_行业公开数据包.md` 中将重定向链接解析为**具体文章页真实 URL 或海外上市公司官方 IR PDF 链接 + `must_contain` 核验词**（严禁只记根域名）；海外官网遇 WAF/403 时优先找官方 IR PDF 或同步锁定国内白名单财经/电子媒体（财联社/证券时报/经济日报/集微网等）转引页，直接供 Step 5B `auto_evidence_capture.py` 自动截红框图。
- **硬闸门**：必须把 `03_段落级大纲.md` 发给研究员拍板后再进入 Step 3，不得跳过确认直接写长文。

### Step 3：多路并发撰稿与统稿汇总（每段 200–300 字、不超过 350 字、图/表穿插、无连续纯文字）
- 按章节并发派发子任务写 `04_分节草稿\*.md`（只喂规范 + `01`/`02` 共享锚点 + 本节大纲与资料包）。
- **文风与合规硬约束**（详见 `style_guide.md`）：
  - **正文不要连续堆砌数字、不分析财务费用率**：严禁在正文里逐年/逐季报数据流水账（具体序列留给图表与表格，正文只点 1–2 个最新关键锚点并聚焦趋势与因果推演），费用率分析与图表均不单列财务费用率；
  - 整体采用**建设性/偏乐观卖方框架**，不过度堆砌风险段落；原则上**不写无公开出处的定性狠话**，确有一手出处的硬判断须同步建 `type: "text"` 底稿；
  - 严禁引用友商卖方研报（如高盛/大摩/中信/中金/华泰等）及非白名单论坛/自媒体；
  - 盈利预测与估值未由研究员提供模型数字前，统一使用 `[待模型填入]` 占位，严禁杜撰 EPS/目标价/评级。
- 合并统稿生成 `05_完整初稿.md`、`report_meta.json`（首页摘要正文严格 `≤ 850 字` 且不出现可比公司名）、`charts.json` 与 `06_证据清单.json`。

### Step 3.5：红队审稿（调用 `deep-report-review`）
- 切换到或遵循 `deep-report-review` Skill，首选 Antigravity 内置 **Claude Opus 5.5**（支持配额切换至 Sonnet 5.5 / Gemini 4 High 或外部 ChatGPT 回填），直接扫正文 + 联网核查（仅异常数字定点查 PDF 对应页），输出绑定 `draft_sha256` 的 `05_红队审稿意见.md`（兼容 `_Claude.md`）并完成定点修订。

### Step 4：研究员审稿确认（盈利预测与估值一律保留 `[待模型填入]`）
- **AI 严禁替研究员写或填任何盈利预测、分业务营收/毛利率预测、PE、目标价与评级**，全文及首页摘要中对应位置一律保持 `[待模型填入]` 占位。
- 本步仅由研究员审定修订后的前几章正文逻辑与事实，确认无误即进入 Step 5 出图、渲染 Word 与打包底稿；盈利预测与估值由研究员在收到最终 Word 后自行刷模型并配合国金插件填入。

### Step 5：三端出图、Word 渲染、工作底稿与门禁验收
- 按顺序执行 `deep-report-charts` 与 `deep-report-workpaper`。
- **AI 交付验收标准（`--strict`）**：三端全部通过 `--strict`（`exit code = 0`，0 🔴 错误，自动输出 `09_对账与质检报告.md`），允许保留 `[待模型填入]` 供研究员后续自行刷模型填入；仅确经四级梯队尝试抓取且有 `attempted_urls` 留痕的闭源付费报告允许标黄 `[INCOMPLETE]`（严禁未抓先弃）。
- **可选终验（`--release`）**：仅当研究员将模型数字回填进 Markdown 且补齐全部付费报告截图、需要机器做零占位终验时再运行。
